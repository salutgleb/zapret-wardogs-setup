# Ручная настройка — с нуля, на чистом zapret

Шпаргалка на случай, если под рукой нет этой сборки: качаете оригинальный zapret от Flowseal и руками доводите его до конфига, который работает с War Dogs.

Это тот же конфиг, что подсказали на Discord-сервере игры. Занимает пару минут.

---

## Итоговый конфиг

| Настройка | Значение |
|---|---|
| Стратегия | `general (ALT11)` |
| Game Filter | `enabled (UDP)` |
| IPSet Filter | `any` |
| Auto-Update Check | `enabled` |
| `lists/list-general.txt` | заменён |
| `lists/list-exclude.txt` | заменён |

В гайде указан zapret **1.9.9d**. На 1.10.0 всё то же самое — пункты меню не менялись.

## Шаги

### 1. Скачать

[github.com/Flowseal/zapret-discord-youtube/releases/latest](https://github.com/Flowseal/zapret-discord-youtube/releases/latest) → архив `zapret-discord-youtube-*.zip`

### 2. Разблокировать

ПКМ по архиву → **Свойства** → внизу галочка **«Разблокировать»** → **Применить** → **ОК**

Пропустите этот шаг, если распаковываете через 7-Zip или PeaZip.

### 3. Распаковать

В путь **без кириллицы и пробелов**. Например `C:\zapret`.

### 4. Заменить два файла в `lists\`

Возьмите из этого репозитория:

- [`lists/list-general.txt`](lists/list-general.txt) — 105 строк
- [`lists/list-exclude.txt`](lists/list-exclude.txt) — 129 строк

**Сначала сохраните оригиналы** — переименуйте в `list-general.txt.bak` и `list-exclude.txt.bak`. Если что-то пойдёт не так, вернёте обратно.

Затем положите новые файлы на их место.

> Эти списки — надстройка над штатными: все домены Discord и YouTube из оригинала на месте, ничего не удалено. Добавлены Cloudflare и `codefusion.technology` — это античит War Dogs.

### 5. Запустить `service.bat`

ПКМ → **«Запуск от имени администратора»**.

Дальше по пунктам меню:

**Game Filter → UDP**

```
Нажать 4  →  откроется подменю  →  нажать 3  (UDP only)
```

В главном меню должно стать: `4. Game Filter [enabled (UDP)]`

**IPSet Filter → any**

```
Нажать 5  →  посмотреть, что в скобках  →  жать 5 ещё раз, пока не станет [any]
```

⚠️ Это **переключатель по кругу**, а не выбор из списка. Порядок такой:

```
loaded  →  none  →  any  →  loaded  →  ...
```

Поэтому может понадобиться нажать 5 два раза. Ориентируйтесь на то, что в скобках, а не на число нажатий.

**Auto-Update Check → enabled**

```
Посмотреть на пункт 6. Если там [enabled] — не трогать.
Если [disabled] — нажать 6.
```

**Выйти из меню**

```
Нажать 0
```

### 6. Запустить стратегию

Двойной клик по **`general (ALT11).bat`**.

Появится окно `winws.exe` (свернётся в панель задач, иконка замочка). Не закрывайте его — закроете, обход выключится.

### 7. Проверить

Откройте Discord и War Dogs.

Если не работает — пробуйте другие стратегии: `general (ALT).bat`, `general (ALT2).bat`, `general (FAKE TLS AUTO).bat` и так далее. **Перед запуском новой закройте предыдущую** (ПКМ по замочку в трее → закрыть, либо диспетчер задач → `winws.exe` → снять задачу).

Стратегии перестают работать со временем и зависят от провайдера — это нормально, перебор неизбежен. Ровно от этого перебора избавляет [`AUTO-PICK.bat`](AUTO-PICK.bat) из этой сборки.

## Голосовой чат Discord

Если текст работает, а голос висит на «подключении» — нужны записи в `hosts`:

```
service.bat  →  9. Update Hosts File
```

Если файл неактуален, откроется блокнот с нужным текстом и папка с `hosts`. Скопируйте всё из блокнота в конец файла `hosts`, открыв его редактором **от администратора**, и сохраните.

На машине, где диск откатывается после сессии, это придётся повторять каждый раз.

## Если что-то сломалось

| Симптом | Что делать |
|---|---|
| Тормозят посторонние сайты | Это `IPSet any`. Верните в `loaded`: жать 5, пока не встанет |
| `winws.exe` не запускается | Антивирус забрал WinDivert — добавьте папку в исключения |
| Игра не работает, а сайты да | Проверьте, что Game Filter именно `enabled (UDP)` |
| Всё сломалось | Верните `.bak`-копии списков и жмите `2. Remove Services` |
| Непонятно, что происходит | `11. Run Diagnostics` — покажет конфликты и типовые причины |
